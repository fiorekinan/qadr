# Qadr – Ramadan Productivity Guide

## Short Description
Qadr is a Ramadan-focused website designed to help users stay productive and consistent in their worship during the holy month. The website provides several helpful tools such as prayer tracking, Qur'an reading progress tracking, fasting tracking, an imsakiyah schedule, a dzikir counter, and a zakat calculator. The main goal of this website is to help users organize and monitor their worship activities throughout Ramadan.

---

## Tech Stack
The technologies used to develop this website include:

- **HTML5** for the website structure  
- **CSS3** for styling and user interface design  
- **JavaScript (Vanilla JS)** for website logic and interactivity  
- **Google Fonts (Poppins)** for typography  
- **MyQuran API** for retrieving prayer and imsakiyah schedule data
- **Figma** for ui design

---

## Main Features

The main features that are currently functioning well in the website include:

### Ramadan Tracker
- Fardhu prayer tracker (Subuh, Dzuhur, Ashar, Maghrib, and Isya)
- Progress bar to display the percentage of completed daily prayers

### Qur'an Recitation Tracker
- Users can input their target pages and the number of pages they have read
- The system automatically calculates the reading progress

### Fasting Tracker
- A 30-day Ramadan calendar
- Users can mark the days they have completed fasting

### Imsakiyah Schedule
- Displays daily prayer times including Imsak, Subuh, Dzuhur, Ashar, Maghrib, and Isya
- Users can select their city to view the schedule according to their location

### Dzikir Counter
- A simple digital counter to help users count their dzikir

### Zakat Calculator
- Calculates income zakat
- Calculates gold zakat based on the nisab threshold

## Usage

### Running Locally
1. Download or clone this project repository.
2. Open the project folder on your computer.
3. Run the **index.html** file using a web browser.

No additional installation is required because this project uses basic front-end technologies.

### Running Publicly
The website can also be deployed and accessed online using hosting services such as **GitHub Pages** or **Netlify**.
